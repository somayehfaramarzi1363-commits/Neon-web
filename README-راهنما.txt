راهنمای راه‌اندازی سایت NEON WEB + دیتابیس

محتویات:
- index.html: صفحه سایت طراحی وب
- style.css: طراحی مشکی نئونی و واکنش‌گرا
- script.js: منوی موبایل، انیمیشن‌ها و ارسال فرم
- config.js: تنظیمات اتصال Supabase
- database.sql: ساخت جدول سفارش‌ها و Policy امنیتی
- README-راهنما.txt: همین راهنما

مرحله ۱ — ساخت دیتابیس
1. وارد https://supabase.com شو و یک حساب بساز/وارد شو.
2. یک پروژه جدید بساز و رمز دیتابیس را در جای امن نگه دار.
3. در پروژه، SQL Editor را باز کن.
4. محتوای فایل database.sql را اجرا کن. جدول website_orders ساخته می‌شود.
5. از بخش Project Settings / API (یا Connect) آدرس پروژه و کلید عمومی publishable/anon را پیدا کن.

مرحله ۲ — وصل کردن سایت به دیتابیس
1. فایل config.js را با یک ویرایشگر متن باز کن.
2. مقدار supabaseUrl را با آدرس واقعی پروژه جایگزین کن.
3. مقدار supabaseAnonKey را با کلید عمومی publishable/anon جایگزین کن.
4. فایل را ذخیره کن. هر دو مقدار نمونه را باید عوض کنی.
مهم: هرگز service_role/secret key را در فایل‌های سایت قرار نده؛ این فایل‌ها عمومی‌اند.

مرحله ۳ — انتشار در Netlify
1. همه فایل‌های این پوشه (index.html، style.css، script.js، config.js) باید در ریشه پوشه باشند.
2. پوشه web-design-business را روی Deploy دستی Netlify رها کن یا پوشه را zip کن و از روش مناسب انتشار استفاده کن.
3. پس از انتشار، فرم سفارش را آزمایش کن. سفارش آزمایشی با اطلاعات ساختگی بفرست.
4. در Supabase > Table Editor > website_orders بررسی کن که رکورد ایجاد شده باشد.

امنیت و پنل مدیریت
- دیتابیس Row Level Security دارد؛ بازدیدکننده فقط مجاز به INSERT است و نمی‌تواند سفارش‌ها را بخواند.
- این بسته عمداً پنل مدیریت عمومی ندارد؛ برای مشاهده سفارش‌ها وارد داشبورد Supabase شو.
- برای ساخت پنل مدیریت داخل سایت، باید ورود مدیر (authentication) و policyهای جداگانه برای مدیر تنظیم شوند. هرگز با کلید secret یا service_role از مرورگر وصل نشو.
- برای جلوگیری از اسپم در محیط واقعی، بعداً CAPTCHA / محدودسازی نرخ و اعتبارسنجی سمت سرور اضافه کن.
- دیتابیس واقعی تا زمانی که پروژه Supabase ساخته، SQL اجرا و config.js تنظیم نشده، فعال نیست.
